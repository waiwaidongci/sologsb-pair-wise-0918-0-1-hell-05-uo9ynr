# 气瓶混气复核台

潜水店气瓶分压混气（EANx / Trimix）的登记、配气、锁定与签收复核前端。

## 业务规则

1. **登记**：气瓶编号、耐压值、检验日期、残压、目标压力、氧目标（O₂ %）、氦目标（He %）、操作员，并可选残气成分假设（同配比残气 / 压缩空气残气）、是否已接氧清洁专用阀门。
2. **分压步骤自动计算**：按 **氦 → 氧 → 压缩空气顶压** 的安全顺序，根据残气折算后给出每一步“起始表压 → 目标表压、加注量、目标分压、储气组最低压力”，以及取整后的理论终值 O₂/He。
3. **不得开工的阻断项**：
   - 氧含量 > 40% 但未勾选氧清洁专用阀门；
   - 检验日期已过期；
   - 任一在用储气组（He/O₂/Air）压力低于本单所需压力——**保留原目标压力与配比**，只写明原因，不自动降压；
   - 残压折算后数学不可行（需先泄放残气）。
4. **开工锁定**：开工后气瓶与配气单进入锁定状态，步骤按当时气源快照冻结；同瓶重复登记被拦截。
5. **同瓶重复提交**：仅当该瓶还处于“待确认”时更新原记录，**绝不产生第二张单**。
6. **签收前复核**：填入实测 O₂/He 与签收人，偏差超过容许范围（默认 ±1.0 个百分点）时不能签收。
7. **混气档案**：复核通过后归档（含冻结步骤、理论/实测值、操作员与签收人），数据存 localStorage，**重载页面仍可追溯**，并支持按气瓶编号查询单瓶历史。

## 技术栈

React 19 + Vite + TypeScript（纯前端，无后端依赖）
